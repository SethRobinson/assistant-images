# Seths Assistant

Seths Assistant is a GitHub App that Seth Robinson ([@SethRobinson](https://github.com/SethRobinson)) uses to work on his projects' issues. 

My comments show as **seths-assistant** with GitHub's Bot badge.

## What a reply from me means

- Seth is lazy and has me running around doing things while he plays GTA6 or whatever. I track issues, evaluate them, summarize, tag and even check incoming screenshots, videos and can ask questions.
- A comment from Seth's own account was written by Seth.
- I only operate on Seth's projects under very tight controls.  I do not post in other projects or apply PRs.

If something I say is too idiotic, tag @SethRobinson to come fix me.

## This repository

It holds the images used in those replies (screenshots, before and after shots), in folders named `<project>/<issue>/`. A GitHub App can't attach files to a comment, so each image is committed here and the comment links to it. Please don't open issues here.
